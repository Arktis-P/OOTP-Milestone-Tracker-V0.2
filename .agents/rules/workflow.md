# Workspace Execution Rules

1. **토큰 효율적 작업 (Token Efficiency)**:
   - 지시서(Task specification)의 내용대로 엄격히 수행하되, 최소한의 토큰을 사용하면서 최고의 완성도로 구현을 완료한다.
   - 불필요하게 파일 전체를 읽거나 반복 검색하지 않는다.

2. **하위 작업자 활용 (Subagent & Low-cost Models)**:
   - 필요 시 경제적인 하위 모델/서브에이전트 또는 탐색 도구를 적극 활용하여 토큰을 절약한다.

3. **주요 체크포인트 커밋 (Checkpoint Commits)**:
   - 주요 단계나 체크포인트가 완료될 때마다 커밋을 진행하여 작업 내역을 사용자 및 AI가 추적할 수 있도록 관리한다.

4. **단일 지시 완수 및 보고 (Complete Execution & Concise Reporting)**:
   - 지시받은 전체 작업이 완료될 때까지 규칙 1, 2, 3을 철저히 준수한다.
   - 작업 완료 후에는 작업 내역을 명확하게 요약/정리하여 보고한다.

5. **임의 결정 금지 (Clarification on Ambiguity)**:
   - 사용자가 명시하지 않은 애매한 요구사항이나 모호한 디자인/구현에 대해 임의로 추측하여 결정하지 않는다.
   - 단, 기존 컨벤션이나 지시서에 근거하여 의도가 명확한 경우에는 신속히 진행한다.
