# Baseball Template V2 Assets

이 폴더는 첨부 9:16 레퍼런스 기반 새 카드 디자인용 준비 자산이다.

## 공통

- `common/card_shell.svg`: 앞/뒤, 타자/투수 모두 공유하는 외곽 프레임
- `common/front_header.svg`: 앞면 상단 프레임
- `common/photo_frame.svg`: 선수 이미지 경계
- `common/position_badge.svg`: 포지션 배지
- `common/front_stats_rail.svg`: 앞면 하단 6스탯 영역
- `common/back_header.svg`: 뒷면 상단 프레임
- `common/section_panel.svg`: 뒷면 각 데이터 섹션
- `common/rating_track.svg`, `common/rating_fill.svg`: 20–80 막대
- `common/divider.svg`: footer용 얇은 선

## 역할별

- `batter/field_diamond.svg`
- `pitcher/velocity_banner.svg`

텍스트는 SVG에 포함하지 않는다. 실제 문자열/수치/로고/선수 이미지는 렌더러가 합성한다.

현재 단계에서는 기존 `templates/baseball/`을 대체하지 않는다.
