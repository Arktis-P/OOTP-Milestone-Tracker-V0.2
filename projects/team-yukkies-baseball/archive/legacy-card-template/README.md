# Legacy Card Template Archive

이 폴더는 현재 사용하지 않는 과거 TEAM YUKIES 카드 템플릿의 보관소입니다.

보관 대상:

- 과거 카드 컴포넌트/스튜디오/핸드오프/템플릿 문서
- Python 기반 카드 레이아웃/렌더러/스튜디오
- 구형 SVG 템플릿(`templates/baseball`, `baseball_v2`, `components`)

## 중요

현재 카드 구현은 이 폴더가 아니라 다음 경로를 기준으로 합니다.

`../../card-template-html/`

이 Archive의 파일은 복구나 과거 비교가 필요한 경우에만 참조하며, 신규 기능을 여기에 추가하지 않습니다.
