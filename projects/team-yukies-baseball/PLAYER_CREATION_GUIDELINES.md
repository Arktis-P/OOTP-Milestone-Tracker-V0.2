# 팀 윳키즈 캐릭터 야구선수화 기준

## 1. 목적

이 문서는 애니메이션·게임·만화 등 서브컬처 캐릭터를 **현실 야구선수로 재해석**할 때 사용하는 공통 기준이다.

목표는 캐릭터의 원작 설정을 그대로 숫자로 옮기는 것이 아니라, 캐릭터의 성격·신체능력·행동양식·전투/경기 스타일·판단력 등을 조사한 뒤 **현실 야구에서 납득 가능한 선수 프로필**로 번역하는 것이다.

능력치 항목은 모바일 야구 게임처럼 한눈에 선수 성향을 파악할 수 있는 핵심 항목으로 단순화한다. 다만 각 수치의 의미와 수준은 특정 게임의 밸런스를 복사하지 않고, 현실 야구와 20–80 스카우팅 스케일을 기준으로 한다.

최종 구조는 **직관적인 핵심 능력치 → 20–80 평가 → 필요 시 전통적 5툴 요약 → 선수 유형/스카우팅 리포트** 순으로 사용한다.

---

## 2. 기본 입력

사용자는 선수 생성 시 아래 정보를 제공한다.

### 필수 입력

- **캐릭터 이름**
- **등장 작품/시리즈**
  - 동명이인 또는 다른 버전과 혼동하지 않기 위한 식별 정보
- **희망 포지션**
  - 예: C, 1B, 2B, 3B, SS, LF, CF, RF, SP, RP
- **기본 선수 유형**
  - 예: 공수겸장 유격수, 컨택 중심 2루수, 장타형 코너 외야수, 강속구 선발, 제구형 선발, 파워 불펜 등

### 선택 입력

사용자가 원하면 다음 항목도 지정할 수 있다.

- 투타
- 세부 역할
  - 리드오프, 중심타선, 테이블세터, 수비형 백업, 에이스, 이닝이터, 셋업맨, 마무리 등
- 특별히 강조하거나 피하고 싶은 능력
- 선수의 예상 커리어 방향
- 특정 캐릭터 해석 기준 또는 버전

사용자가 명시한 방향은 우선적으로 존중한다.

단, 조사 결과 다른 포지션이나 역할이 캐릭터에 현저히 더 자연스럽다고 판단되면 기존 입력을 무시하지 않고 다음과 같이 처리한다.

1. 사용자 지정 포지션 기준 선수안을 먼저 만든다.
2. 별도로 **추천 포지션/역할**을 제시한다.
3. 추천 이유를 캐릭터 특성과 야구 포지션 요구 능력의 대응 관계로 설명한다.

## 3. 조사 원칙

### 3.1 자료 우선순위

캐릭터 분석 시 근거의 우선순위는 다음과 같다.

1. 공식 프로필·공식 설정
2. 원작에서 반복적으로 확인되는 행동과 능력
3. 공식 애니메이션/게임 등 주요 미디어에서의 일관된 묘사
4. 신뢰할 수 있는 설정 자료집·공식 인터뷰
5. 팬 위키 등 2차 자료
6. 제한적인 추론

팬덤의 밈, 단발성 개그 장면, 과장된 연출만으로 높은 능력치를 부여하지 않는다.

### 3.2 버전 혼합 금지

동일 캐릭터라도 작품 시점·미디어·각성 전후 등에 따라 능력이 크게 다를 수 있다.

사용자가 특정 버전을 지정했다면 그 버전을 우선한다. 지정이 없다면 가장 대표적인 본편 버전을 기준으로 하며, 서로 다른 버전의 최고점만 조합해 과도하게 강한 선수를 만들지 않는다.

### 3.3 불확실성

근거가 부족한 항목은 임의로 강하게 만들지 않는다.

근거가 약한 능력은 45~55의 중립 범위를 기본값으로 삼고, 추론이 포함된 경우 평가 근거에 명시한다.

## 4. 현실 야구 기준의 20–80 스카우팅 스케일

팀 윳키즈 선수 평가는 실제 야구 스카우팅에서 널리 쓰이는 **20–80 스케일**을 사용한다.

기준점은 **메이저리그 선수의 해당 도구 평균 = 50**이다.

| 등급 | 의미 |
|---:|---|
| 20 | 극단적으로 낮음 / 프로 수준에서 심각한 약점 |
| 30 | 매우 낮음 |
| 40 | 평균 이하 |
| 45 | 약간 평균 이하 |
| 50 | 메이저리그 평균 |
| 55 | 약간 평균 이상 |
| 60 | 확실한 평균 이상 / Plus |
| 65 | 매우 우수 |
| 70 | 엘리트 / Plus-Plus |
| 75 | 리그 최상위권 |
| 80 | 세대급·극단적 최상위 능력 |

기본 평가는 **5 단위**로 작성한다.

### 4.1 등급 분포 원칙

50은 낮은 점수가 아니다. 메이저리그 평균 수준의 도구를 의미한다.

- 40~60: 대부분의 정상적인 메이저리그 도구가 위치하는 범위
- 65: 해당 능력이 명백한 강점
- 70: 리그에서도 손꼽힐 수준
- 75: 극소수만 도달
- 80: 해당 시대 최고 수준을 논할 정도의 능력

캐릭터가 원작에서 강하거나 인기 있다는 이유만으로 70~80을 부여하지 않는다.

한 선수가 여러 항목에서 70 이상을 받는 경우에는 그만큼 강한 원작 근거와 야구적 해석 근거가 모두 필요하다.

### 4.2 현실성 원칙

모든 캐릭터는 **현실 세계의 인간 야구선수로 변환되었다고 가정**한다.

따라서 다음은 직접 적용하지 않는다.

- 마법으로 공을 가속
- 초능력으로 미래를 봄
- 인간을 초월한 근력으로 비현실적 타구를 만듦
- 순간이동으로 수비 범위를 넓힘
- 비행 능력으로 홈런 타구를 잡음

이러한 설정은 캐릭터의 특징을 설명하는 근거로는 사용할 수 있지만, 실제 야구에서는 현실적인 운동능력·반응속도·판단력·기술로 재해석한다.

## 5. 야수 핵심 능력치

야수는 다음 원본 능력치와 계산 능력치를 사용한다. 원본 스카우팅 등급은 20–80, 기본적으로 5 단위다.

### 5.1 Contact (`contact`)
공을 지속적으로 맞히고 안타성 타구를 만드는 능력.

### 5.2 Power (`power`)
홈런과 강한 장타를 생산하는 능력.

### 5.3 Gap Power (`gap_power`)
외야 사이와 펜스까지 타구를 보내 2루타·3루타를 생산하는 능력. Power와 분리하여 평가한다.

### 5.4 Discipline (`discipline`)
볼/스트라이크 판단, 카운트별 접근, 나쁜 공을 참는 능력. 기존 `eye` 명칭은 사용하지 않는다.

### 5.5 Baserunning (`baserunning`)
타구 판단, 추가 진루, 베이스 위에서의 상황 판단을 포함한 주루 센스.

### 5.6 Stealing (`stealing`)
스타트, 투수 동작 읽기, 도루 성공 가능성을 포함한 도루 능력.

### 5.7 Arm (`arm`)
야수의 송구 강도와 정확성을 종합한 기본 송구 능력.

### 5.8 Speed (`speed`) — 계산값
순수 달리기 속도가 아니라 실전 주자 능력의 요약값이다.

```text
speed = round((baserunning + stealing) / 2)
```

`baserunning` 또는 `stealing`이 변경되면 반드시 다시 계산하여 CSV의 `speed`에 저장한다.

### 5.9 Fielding (`fielding`) — 야수 계산값
카드용 종합 수비 요약값이다. 기본 Arm과 주 포지션 수비 점수를 결합한다.

```text
fielding = round((arm + primary_position_fielding) / 2)
```

예를 들어 주 포지션이 3B라면 `primary_position_fielding = def_3b`이다.
`arm`, `primary_position`, 또는 주 포지션의 `def_*` 값이 변경되면 반드시 다시 계산하여 CSV의 `fielding`에 저장한다.

### 5.10 포지션별 수비

수비는 C / 1B / 2B / 3B / SS / LF / CF / RF 각각의 종합 수비 능력을 별도로 평가한다.

- `def_c`
- `def_1b`
- `def_2b`
- `def_3b`
- `def_ss`
- `def_lf`
- `def_cf`
- `def_rf`

각 포지션 등급에는 포구, 반응, 범위, 송구, 포지션 숙련도를 종합한다.

- 주 포지션의 수비 등급은 필수.
- 실제로 소화 가능한 부포지션도 각각 별도 등급을 준다.
- 소화하지 않는 포지션은 빈 값으로 둔다.

카드 앞면 6개 요약값은 다음을 사용한다.

```text
CON = contact
POW = power
GAP = gap_power
DISC = discipline
SPD = speed
FLD = fielding
```

세부 데이터 정의와 카드 표시 규칙은 `card-template-html/DATA_SCHEMA.md`를 따른다.

## 6. 포수 추가 평가

포수는 일반 야수 평가에 다음 항목을 추가한다.

### Receiving

투구를 안정적으로 받아내는 능력.

### Blocking

원바운드·폭투성 공을 몸으로 막아내는 능력.

### Throwing

도루 저지를 위한 송구 능력.

기본 Arm 레이팅을 바탕으로 포수 특유의 빠른 송구 동작, 릴리스, 정확도를 함께 고려한다. 필요하면 설명에서 팝 타임 성향을 별도로 기술한다.

### Game Calling

투수 리드와 경기 운영 능력.

평가 요소:

- 상대 분석
- 전략적 사고
- 기억력
- 의사소통
- 침착함
- 상황 판단

## 7. 투수 핵심 능력치

투수는 다음 핵심 능력치와 개별 구종을 사용한다. 레이팅은 20–80, 기본적으로 5 단위다.

### 7.1 Stuff (`stuff`)
헛스윙과 불완전한 타격을 만들어내는 전반적인 타자 제압 능력.

### 7.2 Movement (`movement`)
공의 움직임과 배럴 회피, 강한 타구 억제 능력.

### 7.3 Control (`control`)
볼넷을 억제하고 스트라이크를 안정적으로 던지는 능력.

### 7.4 Command (`command`)
원하는 코스와 높이에 공을 배치하는 능력.

### 7.5 Stamina (`stamina`)
경기에서 구위와 투구 동작을 얼마나 오래 유지하는지 평가한다.

### 7.6 Holding (`holding`)
주자 견제, 투구 동작 관리, 도루 억제 능력을 평가한다.

### 7.7 Pitchability (`pitchability`)
구종 배합, 타자 상대 계획, 카운트 운영, 경기 중 조정 능력을 종합 평가한다.

### 7.8 Fielding (`fielding`)
번트·투수 앞 땅볼·베이스 커버 등 투수 자신의 수비 능력. 투수는 이 값을 직접 평가하며 야수처럼 파생 계산하지 않는다.

### 7.9 Velocity (`velocity_kmh`)

20–80으로 변환하지 않고 **투수가 대표적으로 사용하는 속구 계열 구종의 평균 구속을 km/h로 기록**한다.

`velocity_pitch` 같은 별도 대표 구종 필드는 사용하지 않는다.

예:

```text
velocity_kmh = 153
```

구속은 OVR에 직접 중복 반영하지 않는다. 구속의 위력은 Stuff를 결정하는 근거 중 하나로 사용한다.

### 7.10 개별 구종

현재 공식 구종 레이팅은 다음 10개만 사용한다.

- Four-seam Fastball (`pitch_four_seam`)
- Sinker (`pitch_sinker`)
- Cutter (`pitch_cutter`)
- Slider (`pitch_slider`)
- Changeup (`pitch_changeup`)
- Curveball (`pitch_curveball`)
- Splitter (`pitch_splitter`)
- Sweeper (`pitch_sweeper`)
- Slurve (`pitch_slurve`)
- Knuckleball (`pitch_knuckleball`)

구종별 개별 구속은 저장하지 않는다. 각 구종 값은 그 구종의 종합 품질을 뜻하며, 사용하지 않는 구종은 빈 값으로 둔다.

## 8. 계산값 및 자동 재계산 규칙

`speed`, 야수 `fielding`, `overall`, `serial`은 **계산값**이다. 사람이 독립적인 스카우팅 판단으로 임의 조정하지 않는다.

선수 행의 원본 정보나 관련 레이팅이 수정될 때마다 해당 계산값을 다시 계산하여 `PLAYER_RATINGS.csv`에 저장한다. 카드 렌더러도 같은 계산식을 사용해 오래된 계산값이 표시되지 않도록 한다.

### 8.1 Birthday 저장 형식

생일은 연도 없이 `MM-DD` 형식으로 저장한다.

```text
09-14
09-20
```

표시할 때 필요한 `SEP 14`, `September 14` 등의 형태는 렌더러에서 변환한다.

### 8.2 Speed

```text
speed = round((baserunning + stealing) / 2)
```

### 8.3 야수 Fielding

```text
fielding = round((arm + primary_position_fielding) / 2)
```

투수의 `fielding`은 직접 평가값이므로 이 식을 사용하지 않는다.

### 8.4 Overall — OVR v1

OVR은 20–80 범위의 **1 단위 정수 계산값**이다. 최종 결과는 가장 가까운 정수로 반올림하고 20–80으로 제한한다.

#### 타자

```text
BAT =
  contact     × 0.30
+ power       × 0.30
+ gap_power   × 0.15
+ discipline  × 0.25
```

포지션별 OVR:

| 주 포지션 | 계산 |
|---|---|
| DH | BAT × 0.95 + speed × 0.05 |
| C | BAT × 0.72 + fielding × 0.23 + speed × 0.05 |
| 1B / LF / RF | BAT × 0.88 + fielding × 0.07 + speed × 0.05 |
| 2B / 3B | BAT × 0.85 + fielding × 0.10 + speed × 0.05 |
| SS / CF | BAT × 0.75 + fielding × 0.20 + speed × 0.05 |

#### 투수

선발:

```text
SP OVR =
  stuff      × 0.30
+ movement   × 0.20
+ control    × 0.18
+ command    × 0.17
+ stamina    × 0.12
+ fielding   × 0.03
```

불펜/마무리:

```text
RP/CL OVR =
  stuff      × 0.38
+ movement   × 0.22
+ control    × 0.18
+ command    × 0.17
+ stamina    × 0.02
+ fielding   × 0.03
```

`holding`, `pitchability`, `velocity_kmh`, 개별 구종 레이팅은 OVR v1에 직접 중복 반영하지 않는다. 이 값들은 선수 프로필과 세부 능력을 설명하는 독립 레이팅이며, OVR 공식 버전을 변경할 때만 가중치 변경을 검토한다.

### 8.5 Serial Number

시리얼은 다음 정보를 이어 붙여 자동 계산한다.

```text
{TEAM}{YY}{GRADE}{THEME}{NUMBER}{POSITION}
```

필드:

- `team_code`: 2자리 팀 코드. 팀 윳키즈 = `YK`
- `card_year`: 발행 연도 뒤 2자리. 2026 = `26`
- `card_grade`: 카드 등급 숫자 1자리. 현재 Common = `1`; 높은 등급일수록 더 높은 숫자를 사용한다.
- `card_theme`: 카드 테마 번호. 시리얼에서는 2자리 zero-padding. Theme 1 = `01`
- `uniform_number`: 등번호. 시리얼에서는 `00`~`99` 두 자리
- `primary_position`: 아래 포지션 코드를 사용

포지션 코드:

## 9. 신체·정신 특성의 야구적 번역 규칙

캐릭터 특성은 다음과 같은 방향으로 번역할 수 있다.

| 캐릭터 특성 | 주요 야구 능력 후보 |
|---|---|
| 강한 근력 | Power, Arm, Velocity |
| 폭발적인 움직임 | Speed, Fielding, Velocity |
| 민첩성 | Speed, Fielding, Baserunning |
| 뛰어난 반사신경 | Contact, Fielding, 포수 Receiving |
| 정밀한 손기술 | Contact, Arm, Command |
| 높은 집중력 | Contact, Fielding, Control, Command |
| 냉정한 판단 | Eye, Baserunning, 투구 운영 |
| 전술적 사고 | Eye, Game Calling, 투구 운영 |
| 끈기·체력 | Stamina, 장기적인 수비 안정성 |
| 대담함 | 적극적 주루, 공격적 타격 또는 투구 성향 |
| 높은 학습 능력 | Contact, Command, 구종 완성도에 대한 보조 근거 |
| 리더십 | 포수 리드, 투수 운영, 팀 내 역할 설명 |

이 표는 자동 환산표가 아니다.

예를 들어 '머리가 좋다'는 이유만으로 Plate Discipline 70을 부여해서는 안 된다. 실제로 상황을 관찰하고 패턴을 읽으며 침착하게 판단하는 모습이 반복적으로 확인되어야 높은 평가의 근거가 된다.

## 10. 사용자 지정 선수 유형의 적용

사용자가 지정한 **선수 유형은 결과의 방향을 정하는 제약 조건**으로 사용한다.

예:

- "장타형 1루수"라면 Power가 선수의 핵심 능력이 되도록 설계한다.
- "컨택형 2루수"라면 Contact와 Fielding 중심으로 해석한다.
- "강속구 선발"이라면 Velocity와 Stuff를 핵심으로 하되 Stamina와 최소한의 보조 구종을 확보한다.
- "마무리 투수"라면 짧은 이닝에서 높은 Stuff를 낼 수 있는 프로필을 우선한다.

사용자가 **거포, 에이스, 공수겸장, 수비형, 강속구**처럼 선수의 정체성을 명시한 경우, 그 정체성을 대표하는 핵심 능력치는 원칙적으로 **60 이상**을 우선 검토한다. 다만 캐릭터 설정과 명백히 충돌하거나 전체 선수군의 밸런스를 심하게 훼손하면 이유를 설명하고 조정할 수 있다.

그러나 캐릭터 해석과 완전히 충돌하는 능력치를 억지로 부여하지 않는다.

충돌이 클 경우 다음과 같이 보고한다.

- 사용자 요청 유형
- 캐릭터 분석상 충돌 요소
- 요청을 최대한 유지한 선수안
- 더 자연스러운 대체 유형

---

## 11. 포지션 추천 규칙

사용자가 지정한 포지션을 기본값으로 사용한다.

AI는 다음 경우에만 대체 포지션을 적극적으로 추천한다.

- 해당 포지션에서 요구되는 핵심 도구가 캐릭터와 현저히 맞지 않음
- 다른 포지션에서 캐릭터의 특징이 훨씬 자연스럽게 살아남
- 지정 포지션을 유지하려면 다수 능력치를 근거 없이 보정해야 함

대표적인 포지션 요구 특성:

| 포지션 | 특히 중요한 요소 |
|---|---|
| C | 판단력, Receiving, Blocking, Arm, Game Calling |
| 1B | Power, Contact, 기본 포구 능력 |
| 2B | Fielding, 민첩성, 빠른 판단 |
| 3B | 반응속도, Arm, Power |
| SS | Fielding, Arm, 민첩성 |
| LF | Contact/Power 중심, 수비 부담 상대적으로 낮음 |
| CF | Speed, Fielding, 판단력 |
| RF | Arm, Power, 타격 |
| SP | 최소 3개 수준급 구종, Control/Command, Stamina |
| RP | 높은 Stuff, 강한 핵심 구종 |
| CL | 높은 Stuff, 위기 대응, 명확한 결정구 |

이 표는 절대 규칙이 아니라 선수 해석의 가이드다.

## 12. 선수 전체 수준과 능력치 인플레이션 방지

캐릭터를 야구선수로 만드는 과정에서 가장 경계해야 할 것은 모든 선수가 스타가 되는 것이다.

### 원칙

- **50은 메이저리거 평균**이다.
- 약점이 없는 선수는 매우 드물다.
- 캐릭터의 대표적인 강점 1~3개가 선수의 핵심 도구가 되도록 한다.
- 캐릭터의 약점도 야구 능력에 반영한다.
- 65 이상의 능력은 명확한 캐릭터 근거가 필요하다.
- 70 이상의 능력은 해당 캐릭터의 대표적인 특징이어야 한다.
- 80은 특별한 경우에만 허용한다.

예를 들어 신체능력과 반응속도가 뛰어나지만 성급하고 정밀성이 떨어지는 캐릭터는 다음과 같이 차별화할 수 있다.

- Speed 70
- Fielding 60
- Power 55
- Contact 40
- Eye 35

이처럼 장단점이 분명해야 캐릭터 간 개성이 유지된다.

## 13. 능력치 결정 절차

각 캐릭터는 아래 순서로 처리한다.

### Step 1. 사용자 입력 확인

- 이름
- 시리즈
- 희망 포지션
- 선수 유형
- 추가 요구사항

### Step 2. 캐릭터 조사

- 공식 설정
- 신체 특징
- 성격
- 반복적으로 등장하는 행동 특성
- 전투/운동/기술 수행 방식
- 판단력과 집중력
- 체력과 내구성
- 팀 플레이와 리더십

### Step 3. 핵심 캐릭터 특성 추출

3~7개의 핵심 특징으로 압축한다.

예:

- 뛰어난 민첩성
- 빠른 반응속도
- 정밀한 동작
- 높은 집중력
- 낮은 순수 근력

### Step 4. 야구 핵심 능력치로 변환

각 특징이 Contact / Power / Gap Power / Discipline / Speed / Fielding / Baserunning / Stealing / Arm / 포지션별 수비 또는 투수 핵심 능력치 중 무엇과 연결되는지 판단한다.

### Step 5. 사용자 지정 포지션/유형 반영

사용자가 원하는 선수상이 성립하도록 배분하되, 조사 결과와 충돌하는 부분은 별도 표시한다.

### Step 6. 20–80 등급 부여

50 = MLB 평균을 기준으로 상대적인 수준을 결정한다.

### Step 7. 인플레이션 검토

- 65+가 너무 많은가?
- 70+에 충분한 이유가 있는가?
- 명확한 약점이 존재하는가?
- 다른 캐릭터에게도 같은 기준을 적용할 수 있는가?

### Step 8. 포지션 적합성 검토

지정 포지션과 더 자연스러운 대체 포지션이 있는지 평가한다.

### Step 9. 최종 선수 카드 작성

최종 결과에는 능력치뿐 아니라 **왜 그런 선수가 되었는지**를 짧게 설명한다.

## 15. 금지 사항

다음 방식으로 선수를 만들지 않는다.

- 캐릭터 인기나 주인공 여부로 능력치를 높임
- 전투력 순위를 그대로 야구 능력치 순위로 변환
- 초능력을 실제 경기에서 사용할 수 있다고 가정
- 모든 주요 캐릭터에게 60~80만 배정
- 자료가 없는데 임의로 강점을 만들어냄
- 사용자의 포지션/선수 유형을 설명 없이 무시
- 특정 야구 게임의 실제 카드 수치나 밸런스를 그대로 복사
- 한 캐릭터만을 위해 기존 20–80 기준 자체를 변경

## 16. 기준의 목표

좋은 결과는 단순히 강한 선수가 아니다.

최종적으로는 원작을 아는 사람이 선수 프로필을 보았을 때 다음과 같은 인상을 받을 수 있어야 한다.

> "이 캐릭터가 현실에서 야구선수가 되었다면 정말 이런 유형이었을 것 같다."

이를 위해 **캐릭터 해석의 설득력, 현실 야구의 역할 적합성, 전체 선수군 내 일관된 20–80 기준**을 항상 우선한다.
