# Runtime card assets

The HTML template expects these runtime PNG files in this directory:

- `front-background.png`
- `front-batter-overlay.png`
- `front-pitcher-overlay.png`
- `back-batter-overlay.png`
- `back-pitcher-overlay.png`

These files are part of the approved local card-template package and should be copied here unchanged when synchronizing the binary assets.
