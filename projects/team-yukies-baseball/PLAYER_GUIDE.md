# Team Yukies Player Guide

이 문서는 팀 윳키즈 선수 생성 작업의 **단일 진입점**이다. 매 작업마다 상세 기준 문서 5개를 전부 읽을 필요는 없다. 아래 표에서 현재 작업에 필요한 문서만 확인하고, 최종 CSV 기록 단계에서는 반드시 갱신 워크플로를 확인한다.

## 1. 무엇을 할 때 어떤 문서를 보는가

| 작업 | 참조 문서 | 핵심 |
|---|---|---|
| 캐릭터를 어떤 야구선수로 만들지 결정 | `docs/PLAYER_CREATION_GUIDELINES.md` | 포지션, 역할, 플레이스타일, 20–80 레이팅, OVR 공식 |
| 신장·체중·생일·출생지 결정 | `docs/PLAYER_PROFILE_GUIDELINES.md` | 공식값 우선, 추정값 근거, 원작 체형 보존 |
| Trait 1/2/3 선정 | `docs/PLAYER_TRAIT_GUIDELINES.md` | 슬롯별 의미와 허용 Trait |
| 등번호 선정 | `docs/PLAYER_NUMBER_GUIDELINES.md` | 원작 상징 우선, 중복 방지, notes 근거 기록 |
| CSV에 실제 추가·수정 | `docs/PLAYER_RATINGS_WORKFLOW.md` | 파생값 재계산, theme_index, serial, 검증 |
| 카드에서 필드가 어떻게 쓰이는지 확인 | `card-template-html/DATA_SCHEMA.md` | 카드 표시 필드와 데이터 스키마 |

단일 데이터 원본은 `PLAYER_RATINGS.csv`다.

## 2. 기본 작업 순서

```text
1. 캐릭터 자료 조사
2. 포지션·역할·선수 유형 결정
3. 신상정보 결정
4. 원본 레이팅 결정
5. Trait·등번호 결정
6. speed / fielding / overall 계산
7. theme_index / serial 계산
8. scouting_report / notes 작성
9. PLAYER_RATINGS.csv 기록
10. 카드 템플릿 확인
```

### 빠른 참조 규칙

- **포지션/능력치가 쟁점**이면 `PLAYER_CREATION_GUIDELINES`만 먼저 본다.
- **키·체중·출생지가 쟁점**이면 `PLAYER_PROFILE_GUIDELINES`를 추가로 본다.
- **Trait만 고치는 작업**이면 `PLAYER_TRAIT_GUIDELINES`만 확인하면 된다.
- **등번호만 고치는 작업**이면 `PLAYER_NUMBER_GUIDELINES`와 serial 재계산을 위해 `PLAYER_RATINGS_WORKFLOW`를 확인한다.
- **CSV를 실제 수정하는 작업**은 종류와 관계없이 마지막에 `PLAYER_RATINGS_WORKFLOW` 검증을 거친다.

## 3. 공통 프로젝트 원칙

- 캐릭터의 인기나 전투력 자체를 그대로 높은 OVR로 바꾸지 않는다.
- 20–80 원본 레이팅은 원칙적으로 5 단위다. `speed`, 야수 `fielding`, `overall`은 계산된 1 단위 정수다.
- 공식 정보가 없으면 추론할 수 있지만 `notes`에 공식값과 프로젝트 추정값을 구분한다.
- 신체 프로필은 현실 프로야구 체형에 맞추기 위해 벌크업하지 않는다. 원작의 체형과 캐릭터성을 우선한다.
- 자연스러운 보조 포지션은 기록하되, 멀티포지션이라는 이유로 수비 수치를 부풀리지 않는다.
- 투수의 `groundball_pct`는 20–80 레이팅이 아닌 0–100% 성향 지표이며 OVR에 직접 넣지 않는다.

## 4. 선발투수 역할 등급

선발투수는 팀 내 고정 순번인 `1선발 / 2선발 / 3선발`로 분류하지 않는다. 같은 팀에 1선발급 투수가 여러 명 있을 수 있다.

역할의 질은 다음처럼 표현한다.

- **1선발급** — 어느 로테이션에서도 상위 선발을 맡을 수 있는 에이스급
- **로테이션 홀더** — 안정적으로 정규 선발 로테이션을 지키는 수준
- **5선발급** — 로테이션 말단에서 시즌을 소화할 수 있는 수준
- **임시선발급** — 부상·일정 등에 따라 제한적으로 선발 가능
- **롱릴리프급** — 기본은 불펜이며 필요 시 긴 이닝 또는 스팟 스타트 가능

`role`에는 필요하면 `1선발급 좌완`, `로테이션 홀더 / 이닝이터`처럼 등급과 선수 특성을 함께 기록한다.

## 5. 최종 확인

새 선수를 `CONFIRMED`로 두기 전 최소한 다음을 확인한다.

- 포지션과 역할이 캐릭터 해석에 맞는가
- 신상정보의 공식/추정 구분이 되어 있는가
- 원본 레이팅과 Trait가 상세 기준을 따르는가
- 등번호 근거가 `notes`에 있는가
- 계산값과 serial이 최신인가
- 카드 렌더링에 필요한 필드가 빠지지 않았는가

상세 규칙이 필요할 때만 `docs/`의 해당 문서를 열어 확인한다.
